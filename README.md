### 📱 주요 기능

**모의고사**

- 연도·회차별 시험 응시
- 자동 채점 + 오답 오답노트 저장
- localStorage로 중간저장 (새로고침 대비)

**오답노트**

- 회차별 그룹 보기
- 메모 작성
- AI 토론 (멀티모달 지원-필기)
- 편집

**학습일지**

- 통계
- 자주 다룬 개념
- AI 패턴 분석 + 학습 방향
