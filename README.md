### 📱 주요 기능

**모의고사**

- 연도·회차별 시험 응시
- 자동 채점 + 오답 오답노트 저장
- localStorage로 중간저장 (새로고침 대비)

**오답노트**

- 회차별 그룹 보기
- 메모 작성
- [중요] AI 토론: 파인만 기법(생선모드/선생모드) 
  - 직접 설명할수록 이해가 빠르게 상승한다.
  - 일반적으로 과외, 강의 진행을 보면 교육자가 빠르게 능력이 상승함.
  - 따라서 AI(학생)에게 설명하면서 이해를 높이는 '생선모드'
  - 반면에 AI(선생)에게 질문하면서 이해를 높이는 '선생모드'
